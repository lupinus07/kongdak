# 타로 카드 이미지 출처

- 출처: Wikimedia Commons, 1909~1910년 판 "Pam-A" 스캔 (퍼블릭 도메인으로 표시됨)
- 파일 이름 = 카드 ID (lib/tarot-cards.ts): 00~21 대아르카나, 22~35 완드, 36~49 컵, 50~63 소드, 64~77 펜타클
- 원본 파일명: 대아르카나 `RWS Tarot NN Name.jpg`, 마이너 `Wands01.jpg`·`Cups01.jpg`·`Swords01.jpg`·`Pents01.jpg` (01~14: 에이스~10, 페이지, 나이트, 퀸, 킹)
- 가공: 너비 600px WebP (quality 82)로 축소. 1971년 이후 판본은 쓰지 않는다.
- 정/역방향은 이미지를 따로 만들지 않고 CSS로 180도 돌려서 보여준다.
- 공유 링크 미리보기용 사본: `assets/tarot-og/NN.jpg` (너비 300px JPEG). 미리보기 그림을 만드는 next/og가 WebP를 그리지 못해서 따로 둔다.
